# History

## 1.0.0-preview1

### Added

- Added the dedicated `NanoRoute.HttpListener` adapter package.
- Added `HttpListenerRouter` for routing `HttpListenerContext` instances through the shared NanoRoute pipeline.
- Added `HttpListenerRouterConfig` for adapter-specific router snapshots.
- Added `SimpleHttpListenerHost` for small prefix-based listener hosts with bounded worker queueing and scoped services.
